## Hash Table and Extensible Hash Table

Implementation of a hash table data structure for storing and managing unique strings, using open addressing and linear probing for collision resolution.

The project also implements an extensible hash table that dynamically adjusts its capacity based on configurable load-factor thresholds.

This is an academic project for Object-Oriented Programming

## Key Features

- String insertion, deletion, and lookup.
- Collision resolution using linear probing.
- Tombstone-based deletion.
- Dynamic resizing (expansion and shrinking).
- Custom iterator implementation.
- Operator overloading (+, -, +=, -=).
- Copy constructors and assignment operators.
- Hash table union operations.
- Load-factor management.

## Technologies

- C++
- Object-Oriented Programming
- Data Structures and Algorithms
- Dynamic Memory Management

# Files

- **HashTable.hpp/.cpp**: Core hash table implementation.
- **ExtHashTable.hpp/.cpp**: Dynamically resizing hash table.
- **HashTableIterator.cpp**: Custom iterator.
- **HashTableException.hpp**: Exception handling.
